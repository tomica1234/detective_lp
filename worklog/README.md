# Worklog — 稼働管理アプリ

ブラウザで稼働時間を記録し、今月の合計・分類別の時間・日別の推移を確認するための小さなWebアプリです。

## 起動

`worklog` ディレクトリで、次のコマンドを実行します。

```bash
python3 -m http.server 4173
```

ブラウザで <http://localhost:4173> を開いてください。データはブラウザの `localStorage` に保存されるので、サーバーを止めても同じブラウザなら記録が残ります。

## 使い方

1. 開始時刻と内容分類を入力します。時刻は直接入力することも、「現在」ボタンで現在時刻を入れることもできます。
2. 終了時刻を入れて保存すると完了した記録になります。終了時刻を空欄のまま保存すると「稼働中」になり、履歴の「終了」ボタンから現在時刻で終了できます。
3. ダッシュボードで今月の合計、記録件数、1日あたり平均、最多分類を確認できます。
4. 「最近の記録」の「すべて見る」から履歴の編集・削除・CSV出力ができます。

## アカウントを分ける

画面右上のアカウント名から、アカウントを切り替えたり追加したりできます。アカウントごとに稼働記録とスプレッドシート連携設定が分かれます。既存データがある状態で更新した場合は、自動的に「自分」アカウントへ移行されます。

最初の「自分」アカウントは管理者です。管理者には画面上部に「管理」ボタンが表示され、全アカウントの件数確認と、一般アカウントを管理者へ変更する操作ができます。一般アカウントは記録の入力と、自分のアカウントへの切り替えだけができます。

このアカウント機能は現在のブラウザ内での分離です。ログイン認証を伴う本格的な複数端末・複数ユーザー運用が必要な場合は、別途ユーザー認証サーバーが必要です。

## Googleスプレッドシートへの同期

1. Googleスプレッドシートを1つ作成します。
2. **拡張機能 → Apps Script** を開き、`google-apps-script.gs` の内容を貼り付けて保存します。
3. Apps Scriptの関数一覧から `setupWorklogSheet` を1回実行し、権限を許可します。スプレッドシートに「稼働ログ」シートと見出しが作られます。
4. **デプロイ → 新しいデプロイ → ウェブアプリ** を選び、実行ユーザーを「自分」、アクセスできるユーザーを「全員」にしてデプロイします。
5. 発行されたWebアプリURLをWorklogの「⚙ 連携設定」に貼り付け、「設定を保存」します。
6. 「今すぐ同期」でこのブラウザの記録をシートへ送信できます。「シートから取得」で既存の記録をアプリへ取り込めます。

### 任意のアクセストークン

WebアプリをURLだけで公開したくない場合は、Apps Scriptの**プロジェクトの設定 → スクリプト プロパティ**に、次のプロパティを追加します。

- プロパティ: `WORKLOG_TOKEN`
- 値: 任意の長い文字列

同じ値をWorklogの連携設定に入力してください。

## データ項目

スプレッドシートには、ID、稼働開始、稼働終了、内容分類、大分類、小分類、内容記述、更新日時、アカウントID、アカウント名が保存されます。現在の大分類は「探偵」「LLM」です。小分類は大分類に応じて切り替わります。アプリ側の集計時間は開始・終了の差分から算出され、稼働中の記録は現在時刻までの経過時間として集計されます。小分類の「移動」「プロンプト作成」は選択肢から除外しています。
